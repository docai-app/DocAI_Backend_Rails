現況問題：
目前派發作業時，學生需手動輸入作業代碼（code）才能加入，系統缺乏自動分班與作業自動分派功能。

建議改善：

老師在建立作業時后，在新页面可直接勾選年級、班別或個別學生進行分派，無需再使用代碼。
學生登入帳戶後，系統自動顯示待完成的作業清單。
系統中每位用戶均已具備「學校／姓名／班級／學號」資料；
老師可依據這些資訊選擇其授課年級或班級學生，進行作業分配。
老师只能在本学校内选择班级，而且只选择当前学年内人学生进行分配

作業截止與提醒機制

建議改善：

老師建立作業時可設定截止日期（deadline）。
系統應提供統計功能：可查看各學生的「已交／未交／逾期」狀態。
老師可一鍵發送提醒通知（notification）給尚未提交作業的學生。
